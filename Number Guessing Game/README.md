# Number Guessing Game 🎯

A simple command-line number guessing game developed using Python as part of my **Codveda Technologies Python Development Internship**.

## Features

- Generates a random number between 1 and 100
- Allows the user multiple attempts to guess the number
- Provides feedback when the guess is too high or too low
- Limits the player to a maximum of 10 attempts
- Displays the correct number when the player runs out of attempts
- Handles invalid inputs
- Prevents guesses outside the 1–100 range

## Technologies Used

- Python 3
- Random module

## How to Run

1. Make sure Python 3 is installed.
2. Clone or download this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
python guessing_game.py
